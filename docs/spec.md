# Bloom Lab — specificație

## Scop
Aplicație publică (RO/EN) care te ajută să prepari acasă o cafea mai bună, pe orice metodă, cu o zonă de experimente.

## Decizii (2026-10-27)
- Platformă: web app mobile-first, un singur fișier HTML, fără build.
- Metode: toate (filtru, imersie, espresso, moka, ibric, cold brew) + experimente.
- Funcții v1: ghid pas cu pas + timer, calculator, diagnostic gust, jurnal, laborator (A/B, import).
- Nume de lucru: Bloom Lab.

## Roadmap
1. Testare pe propriile preparări, ajustare rețete.
2. PWA: instalare pe ecran, funcționare offline (service worker).
3. Conturi + sincronizare jurnal (ex. Supabase).
4. Export/import jurnal, profil de boabe, setări de râșniță (clicuri).
5. Monetizare: rețete premium / abonament laborator.
